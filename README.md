Scholarship Management System

About the Project:
 The Scholarship Management System is a simple C programming project developed to manage scholarship applications of college students.

Features:
- Add scholarship application
- View scholarship records
- Check scholarship eligibility
- Store student scholarship details
- Display application information

Technologies Used:
- C Programming
- File Handling

Data Stored:
- Application ID
- Student Name
- Department
- Academic Percentage
- Family Income
- Scholarship Name

How to Run:
1. Open `main.c` in Dev-C++ or any C compiler.
2. Compile the program.
3. Run the program.
4. Select the required option from the menu.
5. Enter the scholarship application details.

Project Files:
- `main.c` – Main C program
- `scholarship_records.txt` – Scholarship application records
- `README.md` – Project documentation
- `output1.png` – Sample program output
- `output2.png`

Objective:
The main objective of this project is to provide a simple system for managing scholarship applications efficiently.
